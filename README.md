# FarmIQ 🌱

스마트팜 교육 시뮬레이션 게임

## 개요

FarmIQ는 IoT 센서 관리, 자동화 농업 시스템, AI 기반 작물 예측을 재미있는 게임플레이를 통해 배울 수 있는 교육용 스마트팜 시뮬레이션 게임입니다.

## 주요 기능

- 🌡️ **실시간 환경 모니터링**: IoT 센서를 통한 온도, 습도, CO2, pH, EC 모니터링
- 🤖 **자동화 제어 시스템**: 관개, 환기, LED 조명 등 자동 제어
- 🌾 **다양한 작물 재배**: 상추, 시금치, 토마토, 파프리카 등 현실적인 성장 시뮬레이션
- 💰 **경제 시스템**: 자원 비용, 시장 가격, 수익 계산
- 📈 **테크 트리**: 업그레이드 시스템을 통한 진행
- 📱 **크로스 플랫폼**: 웹, 데스크톱(Electron), 모바일(PWA) 지원

## 기술 스택

| 카테고리 | 기술 | 용도 |
|---------|------|------|
| 프레임워크 | React 18+ | 컴포넌트 기반 UI |
| 언어 | TypeScript 5+ | 타입 안전성 |
| 스타일링 | Tailwind CSS | 유틸리티 기반 CSS |
| 상태 관리 | Zustand | 경량 전역 상태 관리 |
| 차트 | Recharts | 센서 데이터 시각화 |
| 빌드 | Vite | 빠른 개발 서버 |

## 시작하기

### 필수 조건

- Node.js 18+
- npm 또는 yarn

### 설치

```bash
# 저장소 클론
git clone https://github.com/josens83/FarmIQ.git
cd FarmIQ

# 의존성 설치
npm install

# 개발 서버 시작
npm run dev
```

### 빌드

```bash
# 프로덕션 빌드
npm run build

# 빌드 미리보기
npm run preview
```

## 게임 플레이

1. **게임 시작**: 새 게임을 시작하거나 저장된 게임을 이어하세요
2. **농장 관리**: 그리드에서 작물을 심고 관리하세요
3. **환경 모니터링**: 센서 대시보드에서 환경 조건을 확인하세요
4. **장비 제어**: 히터, 냉각기, 관개 시스템 등을 제어하세요
5. **자동화 설정**: 센서 기반 자동화 규칙을 설정하세요
6. **수확 및 판매**: 작물을 수확하여 수익을 얻으세요

## 프로젝트 구조

```
src/
├── components/          # UI 컴포넌트
│   ├── common/          # 공통 컴포넌트
│   ├── dashboard/       # 센서 대시보드
│   ├── farm/            # 농장 그리드
│   ├── controls/        # 장비 제어
│   └── hud/             # 게임 HUD
├── game/                # 게임 로직
│   ├── engine/          # 게임 엔진
│   └── systems/         # 게임 시스템
├── store/               # Zustand 스토어
├── data/                # 정적 게임 데이터
├── types/               # TypeScript 타입
└── layouts/             # 레이아웃 컴포넌트
```
